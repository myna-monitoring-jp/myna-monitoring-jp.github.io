# 日次公開前QAチェックリスト

## 日付

- [ ] レポート日と曜日が一致
- [ ] 主要時間窓がJSTの直近24時間
- [ ] 72時間バックフィルを実施
- [ ] 発生日・公表日・更新日を区別
- [ ] 直近24時間外は追補ラベル

## 事象

- [ ] 記事ではなく事象単位
- [ ] 転載・系列記事を重複計上していない
- [ ] 前日差分がある
- [ ] サービス層を混同していない
- [ ] 計画停止と障害を区別
- [ ] 窓口混雑をシステム障害としていない

## 数字

- [ ] 影響人数に範囲・分母・基準日
- [ ] 約・最大・可能性を保持
- [ ] 登録率と利用率を区別
- [ ] 延べ人日と人数を区別
- [ ] 一部健保分と事案全体を区別
- [ ] 未公表値を推測していない

## ソース

- [ ] 重要度大に一次情報
- [ ] 一次情報なしは明示
- [ ] URLを取得・検証済み
- [ ] 全外部リンクが別タブ
- [ ] 空リンクなし
- [ ] SNSだけで事実確定していない

## 世論・炎上

- [ ] 全国調査とSNSを別表示
- [ ] SNSに代表性なし注記
- [ ] 実在する反応のみ
- [ ] 反応数に取得日時
- [ ] 既存批判と新規広報反応を分離
- [ ] 予測は広報リスク欄
- [ ] 単発批判を炎上と断定していない
- [ ] 炎上度に根拠

## 表現

- [ ] 「確認されていない」を「ない」と強めていない
- [ ] 公式終了告知なしだけで障害継続と断定していない
- [ ] 不明・未確認・未公表を明記
- [ ] 各カードにA/B/C/Dブロック
- [ ] 前日から大きな動きなしの場合、その旨を明記

## 出力

- [ ] UTF-8
- [ ] `myna_news_YYYY-MM-DD.html`
- [ ] PC・スマホ表示
- [ ] 印刷時にカード分断が少ない
- [ ] HTMLとJSONを保存
- [ ] 訂正履歴を保存
